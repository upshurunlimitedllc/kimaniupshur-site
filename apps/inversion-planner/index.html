Inversion Planner

Instead of asking how to succeed, ask: what would guarantee failure? List every surefire way to fail, score how dangerous each trap is, then invert each one into a preventive action. Avoiding stupidity beats seeking brilliance.

The thing you want to succeed at. One clear sentence.

Step 2 — Guarantee failure

For each trap, name the failure mode, then rate how likely you'd fall into it (1 = unlikely, 5 = almost certain) and the damage if it happened (1 = minor setback, 5 = goal dead). Danger = trap × damage.

Step 3 — Invert each trap

Flip every failure mode into a preventive action. Read the trap, then write the opposite behavior you'd need. The deadliest traps are marked — invert those first.
