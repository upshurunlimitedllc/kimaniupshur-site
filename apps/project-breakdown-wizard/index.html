Project Breakdown Wizard

Turn an overwhelming project into a sequenced task list through guided decomposition. Three rounds — project to milestones, milestones to tasks, tasks to concrete next actions — with missing pieces flagged and vague items sent back for re-splitting.

Round 0 — Name it and define "done"

Round 1 — Milestones

Big projects are won in phases. What are the 3–6 major phases of this project, in order? For each: what must be true before this phase can start?

Round 2 — Tasks

For each milestone: what has to be true before each step? Break the milestone into its tasks — each task should be completable in one sitting or one day.

Round 3 — Concrete next actions

The final split: every task becomes 1–5 concrete next actions. A next action is physical and obvious ("Call Maria at 555-0134"), with a time estimate in minutes.
