# kimaniupshur-site

Source for [kimaniupshur.com](https://kimaniupshur.com) — the Upshur Unlimited, LLC website: books, apps, and resources from Kimani Upshur, M.Ed.

## Contributing

All changes land through pull requests into `main`. Branch protection (enabled 2026-10-19) requires the `validate` site-integrity check to pass and branches to be up to date before merging; direct pushes, force pushes, and branch deletion on `main` are disabled.
